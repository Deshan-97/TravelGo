# **App Name**: Travel GO

## Core Features:

- User Authentication: Implement phone number and password-based authentication using Firebase Authentication.
- Role-Based Dashboards: Create separate dashboards for vehicle owners and administrators.
- Vehicle Management: Vehicle owners can add vehicles with details like type, model, year, license plate, service types, and rates.
- Availability Management: Vehicle owners can manage unavailable dates using a calendar view.
- Hire Request Management: Vehicle owners can view and respond to pending hire requests, including submitting offer prices. The app uses a tool which may automatically calculate suggested prices based on seasonal demand.
- Hire Tracking: Vehicle owners can view accepted hires and update the hire status (start/end).
- Commission Calculation: Calculate and display commission amounts for vehicle owners based on completed hires.

## Style Guidelines:

- Background color: Black (#000000) for a modern, premium feel.
- Foreground color: White (#FFFFFF) for clear readability.
- Accent color: Gold (#FFD700) for buttons and interactive elements. This adds a touch of elegance and draws attention to important actions.
- Font recommendation: 'Poppins', a sans-serif font known for its geometric shapes, is ideal for clear text and app headlines. It also matches the prompts request for bold minimal typography.
- Use clean, line-based icons in white for general UI elements, and gold for interactive or status-related icons.
- Design a mobile-first responsive layout with rounded buttons (12-16px radius) and soft shadows for depth.
- Implement smooth transitions between screens and subtle animations on user interactions to enhance the user experience.
